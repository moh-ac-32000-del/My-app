==================================================

- Multiple devices must access the same cloud data.

- Current local/test financial data is disposable.
- No migration of current experimental data is required.
- Do not design around preserving current local financial data.
- Do not publish before Cloud + Workspace architecture is implemented and tested.
- Maximum intended users: approximately 90.
